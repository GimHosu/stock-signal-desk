# Stock Signal Desk

보유한 미국 주식과 관심 종목을 매일 기술적 지표로 분석해 **매수 / 보유 / 매도** 신호를 보여주는 웹 앱입니다.
관심 종목은 수량과 단가 없이 티커만 등록하며, 손절/익절 규칙을 제외한 같은 규칙으로 분석하고 합계에서는 빠집니다.
AI 없이 규칙 기반으로 계산하므로 API 키나 비용이 들지 않습니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면, 지표 계산, 신호 엔진, 차트 (모두 브라우저에서 실행) |
| `api/chart.js` | Vercel 서버리스 함수. Yahoo Finance 일봉 2년치를 가져오는 프록시 |
| `dev-server.ps1` | 로컬 테스트용 서버 (Node 불필요) |

## 신호 규칙 (점수 합계 −100 ~ +100)

| 규칙 | 점수 |
|---|---|
| 주가가 200일선 위 / 아래 | +15 / −15 |
| 최근 10거래일 골든크로스 / 데드크로스 (50일선 vs 200일선) | +20 / −20 |
| 주가 > 20일선 > 50일선 (정배열) / 역배열 | +10 / −10 |
| RSI < 30 / 30–40 / 60–70 / > 70 | +20 / +5 / −5 / −20 |
| 최근 3거래일 MACD 매수 교차 / 매도 교차 | +15 / −15 |
| (교차 없을 때) MACD가 시그널선 위 / 아래 | +5 / −5 |
| 볼린저밴드 하단 이탈 / 상단 돌파 | +10 / −10 |
| 20일 평균의 2배 넘는 거래량 동반 상승 / 하락 | +5 / −5 |
| 수익률이 손절 기준 이하 (기본 −8%) | −30 |
| 수익률이 익절 기준 이상 (기본 +25%) | −15 |

판정: **+40 이상 강력 매수 · +15 이상 매수 · −15 초과 보유 · −40 초과 매도 · 그 이하 강력 매도**

규칙과 점수는 `index.html`의 `analyze()` 함수에 모여 있어 쉽게 바꿀 수 있습니다.

## 로컬에서 실행

```
powershell -ExecutionPolicy Bypass -File dev-server.ps1
```
브라우저에서 http://localhost:8787 을 엽니다.

## 클라우드 배포 (Vercel, 무료)

1. GitHub에 새 저장소를 만들고 이 폴더를 올립니다.
   ```
   git init
   git add .
   git commit -m "Stock Signal Desk"
   git branch -M main
   git remote add origin https://github.com/<내 계정>/stock-signal-desk.git
   git push -u origin main
   ```
2. https://vercel.com 에 GitHub 계정으로 로그인 → **Add New → Project** → 저장소 선택 → **Deploy**.
   빌드 설정은 건드리지 않아도 됩니다.
3. 발급된 `https://<이름>.vercel.app` 주소로 PC와 휴대폰 어디서든 접속합니다.

## 알아둘 점

- 보유 종목과 설정은 **브라우저(localStorage)에 저장**됩니다. 다른 기기에서도 쓰려면 설정 → 내보내기/가져오기를 이용하세요.
- 페이지를 열 때마다 최신 일봉으로 다시 분석하고, 켜둔 상태에서는 30분마다 갱신합니다. 날마다 신호를 기록해 어제와 신호가 바뀌면 표시합니다.
- 장중에는 마지막 봉이 실시간 가격이라 신호가 장 마감 전까지 바뀔 수 있습니다.
- Yahoo Finance 비공식 API를 사용하므로 예고 없이 막히거나 바뀔 수 있습니다.
- 이 앱의 신호는 기계적 규칙의 결과일 뿐 투자 권유가 아닙니다.
