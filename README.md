# Stock Signal Desk

보유한 미국 주식과 관심 종목을 매일 기술적 지표로 분석해 **매수 / 보유 / 매도** 신호를 보여주는 웹 앱입니다.
관심 종목은 수량과 단가 없이 티커만 등록하며, 손절/익절 규칙을 제외한 같은 규칙으로 분석하고 합계에서는 빠집니다.
장중에는 1분마다 실시간 가격으로 다시 분석하고, 장 마감 후 확정 신호가 바뀌면 텔레그램으로 알려 줍니다.
AI 없이 규칙 기반으로 계산하므로 API 키나 비용이 들지 않습니다.

## 종합 퀀트 분석 (0 ~ 100점)

4개 매트릭스 × 25점. 모든 지표는 일봉(2년) 시세로 계산합니다. 규칙과 점수는 `lib/signal.js` 의 `analyze()` 에 있습니다.

| 매트릭스 | 항목 (배점) |
|---|---|
| **1. 추세** | 정배열 20>50 (4) · 200일선 상회 (4) · 50/200 골든크로스 (3) · MACD 시그널 위 + 0선 위 (5) · DMI +DI>−DI (3) · ADX≥25 상승 (2) · ROC 12일 (2) · 피봇 & 파라볼릭 SAR (2) |
| **2. 모멘텀 반등** | RSI 과매도 (6) · 스토캐스틱 골든크로스 (5) · CCI −100 (4) · 20일 이격도 (4) · 20일 고점 돌파(P&F 근사) (3) · Williams %R (3) |
| **3. 변동성 & 지지선** | 볼린저 %B 하단 (6) · 볼린저 스퀴즈 (5) · 볼린저 중심선 돌파 (4) · ATR 안정 (4) · 엔벨로프 하단 (3) · 켈트너 하단 (3) |
| **4. 시장강도 & 거래량** | 거래량 배수 (5) · 거래량 5/20 골든크로스 (4) · 거래대금 유입 (3) · 매물대 POC 상회 (4) · OBV 매집 (4) · MFI (3) · Volume Oscillator (2) |

보유 종목은 손절 기준 도달 시 −20점, 익절 기준 도달 시 −10점을 반영합니다.

추세 매트릭스와 반등 매트릭스는 서로 반대 상황에서 점수가 나서, 실제 합계는 대부분 15~60점에 모입니다.
그래서 판정 기준은 S&P 500 전 종목 분포(2026-09-29: 중앙값 37 · 상위 5% 50 · 최고 56)에 맞췄습니다.

| 점수 | 등급 | 신호 | 비율(대략) |
|---|---|---|---|
| 55 이상 | S | 강력 매수 | 상위 1% |
| 50 이상 | A | 강력 매수 | 상위 5% |
| 44 이상 | B | 매수 | 다음 15% |
| 35·32 이상 | C | 보유 (32점 이상) | 중간 55% |
| 26 이상 | D | 매도 | 15% |
| 26 미만 | F | 강력 매도 | 하위 10% |

함께 보여 주는 분석
- **다이버전스**: 최근 60일 스윙 고점·저점과 RSI·MACD 히스토그램의 엇갈림 (강세/약세)
- **매매 타점**: 추천 진입가(5% 이내 가장 가까운 지지선), 손절가(60일 저점·ATR, 3~12%), 목표가(위쪽 저항선), 손익비
- **5대 핵심 조건**: 볼린저 하단~중단 · 200일선 상회 · RSI ≤ 40 · MDD 도달률 70% 이상 · 흑자기업(최근 4분기 순이익·영업이익 흑자)
- **펀더멘털 & 밸류에이션**: SEC 공시(XBRL) 기준 최근 4분기 순이익·매출·영업이익률·EPS, 연간 매출 성장률, PER, 최근 1년 배당수익률
- **차트 탭**: 가격 & 볼린저/200일선 · MACD · 스토캐스틱 · RSI · MDD 낙폭
- **종합 진단**: 계산 결과로 규칙에 따라 작성한 총평 · MDD 분석 · 지표 & 다이버전스 · 분할 매수 시나리오 · 위험 요인

## 알림 설정 (텔레그램)

아래를 마치기 전까지 앱은 지금처럼 **이 브라우저에만 저장**하며 정상 동작합니다.

### 1. 저장소 만들기 (Upstash Redis, 무료)
Vercel 프로젝트 → **Storage** 탭 → **Create Database** → **Upstash for Redis** → 무료(Free) 플랜 → 프로젝트에 **Connect**.
필요한 환경변수(`KV_REST_API_URL`, `KV_REST_API_TOKEN`)가 자동으로 추가됩니다.

### 2. 텔레그램 봇 만들기
1. 텔레그램에서 **@BotFather** 를 검색해 대화를 열고 `/newbot` 을 보냅니다.
2. 봇 이름과 아이디(`..._bot` 으로 끝나야 함)를 정하면 **토큰**(`123456:ABC...`)을 줍니다.
3. 방금 만든 봇을 열어 **시작(Start)** 을 누르고 아무 메시지나 한 번 보냅니다.

### 3. 환경변수 넣기
Vercel 프로젝트 → **Settings → Environment Variables** 에 추가합니다.

| 이름 | 값 |
|---|---|
| `APP_PASSWORD` | 앱 접속 비밀번호 (직접 정함) |
| `CRON_SECRET` | 아무 긴 무작위 문자열 (16자 이상) — 매일 자동 실행 인증용 |
| `TELEGRAM_BOT_TOKEN` | BotFather 가 준 토큰 |

저장 후 **Deployments → 최신 배포 ⋯ → Redeploy** 를 눌러야 적용됩니다.

### 4. 채팅 ID 찾고 테스트
1. 앱을 열면 비밀번호를 묻습니다 → `APP_PASSWORD` 입력. 이 기기의 종목 목록이 서버로 올라갑니다.
2. **설정 → 테스트 알림 보내기** → 화면에 나온 숫자를 `TELEGRAM_CHAT_ID` 환경변수로 추가 → Redeploy.
3. 다시 **테스트 알림 보내기** → 텔레그램에 메시지가 오면 완료.
4. **지금 신호 점검** 으로 현재 전체 신호를 텔레그램으로 받아 볼 수 있습니다.

### 알림 동작
- 평일 한국 시간 오전 7시쯤(Vercel 무료 플랜은 최대 1시간 오차) 직전 거래일의 **확정 신호**를 계산합니다.
- 전날 확정 신호와 달라진 종목이 있을 때만 알림을 보냅니다. 새로 추가한 종목은 첫날 기준값만 기록합니다.
- **설정 → 신호 변경이 없어도 매일 아침 요약 받기** 를 켜면 변경이 없어도 매일 전체 신호 요약을 보냅니다.
- 설정 화면에 **마지막 자동 점검** 기록(시각·종목 수·변경 건수·발송 여부·오류)이 표시됩니다.
  하루가 지나도 기록이 없다면 Vercel → Settings → Cron Jobs 의 로그를 확인하세요.
- 장중 잠정 신호는 기록하지 않고, 휴장일에는 알림이 가지 않습니다.

## 재무 정보 (SEC)

- `api/fundamentals.js` 가 SEC 공시 데이터(data.sec.gov companyfacts)에서 계산해 돌려주고, 서버 저장소에 7일간 캐시합니다.
  최근 4분기(TTM) = 최근 연간(10-K) + 올해 누적(10-Q) − 작년 같은 기간 누적.
- 종목과 SEC 등록번호(CIK)는 S&P 500 목록(`lib/universe.js`)에서 찾습니다.
- **S&P 500 밖 종목**까지 조회하려면 Vercel 환경변수 `SEC_USER_AGENT` 에 `이름 이메일`(예: `Hong Gildong hong@example.com`)을 넣으세요.
  SEC 는 연락처가 담긴 User-Agent 로만 티커 목록을 내려줍니다.
- ETF·해외 기업처럼 SEC 재무 공시가 없는 종목은 "재무 정보 없음"으로 표시되고, 흑자기업 조건은 판정에서 빠집니다.
- 배당수익률은 Yahoo 시세의 배당 기록(최근 1년 합계 ÷ 현재가)으로 계산합니다.

## 실적 일정 & 뉴스 (Finnhub)

- Vercel 환경변수 `FINNHUB_API_KEY` 에 [finnhub.io](https://finnhub.io) 무료 API 키를 넣으면 켜집니다 (없으면 "연동 안 됨"으로 표시).
- `api/events.js` 가 종목별 실적 일정(지난 200일 ~ 앞으로 120일)과 최근 7일 뉴스를 받아 1시간 캐시합니다. 앱 비밀번호가 있으면 비밀번호가 필요합니다.
- **실적**: 다음 발표일·시간(장 전/장 후)·예상 EPS, 지난 발표의 EPS 서프라이즈와 발표 후 주가 반응(장 전이면 당일, 장 후면 다음 거래일 등락)
- **뉴스 심리**: `lib/events.js` 의 금융 헤드라인 키워드 사전으로 긍정·부정을 셉니다 (예: beat·upgrade·raises guidance / miss·downgrade·lawsuit·probe). 문맥은 이해하지 못합니다.
- 점수(0~100)에는 넣지 않고, 진단 문장·위험 요인·매매 시나리오에 반영합니다.
  - 실적 발표 7일 이내 → 위험 요인 + "1차 매수는 발표 후로" 안내, 목록에 `📅 실적 D-n` 표시
  - 부정 뉴스 우세 → 위험 요인, 지난 실적 후 −5% 이상 급락 → 위험 요인
- 텔레그램 알림에 "📅 7일 안에 실적 발표" 목록이 붙습니다.
- **헤드라인 한국어 번역**: 서버가 뉴스를 받을 때 함께 번역해 캐시합니다. 기본은 Google 번역 무료 엔드포인트(비공식, 키 불필요)이고,
  환경변수 `DEEPL_API_KEY`([DeepL 무료 키](https://www.deepl.com/pro-api), 월 50만 자)를 넣으면 DeepL 공식 API를 씁니다.
  번역에 실패하면 영어 원문을 보여 주며, 화면에는 번역 아래에 원문을 함께 표시합니다.

## 증시 일정

**증시 일정** 탭(앞으로 30일)과 '내 종목' 화면의 **이번 주 주요 일정** 카드. 시각은 모두 한국 시간입니다. 계산은 `lib/calendar.js`.

| 일정 | 출처 |
|---|---|
| 미국 경제지표 (고용·CPI·PCE·GDP·ISM 등, 예상/이전 값) | ForexFactory 무료 피드 — **이번 주만** 제공, 3시간 캐시 (`api/calendar.js`) |
| FOMC 금리 결정·점도표·의사록 | `lib/calendar.js` 의 `FOMC` 목록 (연준 발표 일정, **2027년 일정은 발표 후 추가 필요**) |
| 휴장일·조기 폐장 | NYSE 규칙으로 계산 (부활절 기준 성금요일 포함) |
| 옵션 만기일·쿼드러플 위칭 | 매월 셋째 금요일 (3·6·9·12월 = 쿼드러플 위칭 + S&P 500 리밸런싱) |
| 내 종목 실적 | 실적 & 뉴스 데이터 |
| 대형주 실적 (시총 상위 20개) | Finnhub 실적 캘린더 (`FINNHUB_API_KEY` 필요), 6시간 캐시 |

텔레그램 아침 알림에 **48시간 안의 주요 일정**(중요 경제지표·FOMC·휴장/조기 폐장·쿼드러플 위칭)이 붙습니다.

## 섹터 · 순환매

**섹터 · 순환매** 탭은 S&P 500 11개 섹터 ETF(XLK·XLC·XLY·XLF·XLI·XLB·XLE·XLV·XLP·XLU·XLRE)를 SPY와 비교합니다. 계산은 `lib/sectors.js`.

- **섹터별 성과**: 1주·1개월·3개월·연초 대비 수익률과 시장 대비 초과 수익(%p), 섹터 안 종목 상태(종목 발굴 스캔 기준 평균 점수·매수 신호 비율·200일선 위 비율), 내 보유·관심 종목
- **RRG(상대 회전 그래프)**: 상대강도 = 100 × (섹터÷SPY) ÷ 그 50일 평균, 모멘텀 = 100 × 상대강도 ÷ 10거래일 전 상대강도
  → 주도 · 약화 · 소외 · 개선 4구역과 최근 6주 이동 경로
- **순환매 신호**: 2주 전과 구역이 바뀐 섹터 (예: 소외→개선 "반등 시작", 주도→약화 "모멘텀 둔화")
- **위험 선호도**: 경기민감 7개 섹터와 방어 4개 섹터의 1개월 초과 수익 차이 (+2%p 이상 Risk-on, −2%p 이하 Risk-off)
- 섹터 행을 누르면 종목 발굴에서 해당 섹터 종목만 점수순으로 보여 주고, 종목 상세에는 소속 섹터의 구역이 표시됩니다.

## 용어 설명

상단 **용어 설명** 버튼과 각 섹션 제목 옆 **?** 버튼으로 앱에 나오는 용어(지표·재무·실적·시장)의 뜻과
"이 앱에서 어떻게 쓰는지"를 볼 수 있습니다. 내용은 `lib/glossary.js` 에 있습니다.

## 종목 발굴

**종목 발굴** 탭은 S&P 500 전 종목(503개)에 같은 규칙을 적용한 결과를 보여 줍니다. 보유 종목이 아니므로 손절/익절 규칙은 빠집니다.

- 서버 저장소가 설정되어 있으면 평일 오전 7시쯤 자동으로 스캔하고, **지금 스캔**은 서버에서 실행됩니다 (약 20~40초).
  설정 전(또는 로컬)에는 이 브라우저에서 직접 스캔합니다 (1~3분).
- 최소 점수, 섹터, 정렬(점수·점수 상승폭·당일 하락·RSI), 검색으로 거를 수 있습니다.
- 이전 스캔 대비 점수 변화(▲▼)와 새로 +40 이상이 된 종목(**신규**)을 표시합니다.
- 행을 누르면 근거를 펼쳐 보고, **+ 관심** 으로 관심 종목에 바로 추가합니다.
- **목록 갱신** 버튼은 위키백과의 최신 S&P 500 구성 종목을 받아 저장하고, 편입·편출된 종목을 보여 줍니다.
  저장된 목록은 다음 스캔(자동·수동)부터 쓰입니다. 서버 저장소가 없으면 이 브라우저에 저장됩니다.
- 앱에 내장된 기본 목록(`lib/universe.js`)은 `scripts/update-universe.ps1` 로 다시 만들 수 있습니다.

## NAS(Docker) 실행

Vercel 없이 시놀로지 NAS 등 Docker 에서 돌릴 수 있습니다. 자세한 절차는 **[DEPLOY-NAS.md](DEPLOY-NAS.md)**.

- `server/index.js` — 외부 패키지 없는 Node 서버. `api/*.js` 를 그대로 실행하고, Vercel Cron 대신
  평일 21:45 UTC 토스 동기화 → 22:00 알림 → 22:15 스캔을 실행합니다 (`TOSS_SYNC_UTC`·`ALERT_UTC`·`SCAN_UTC` 로 변경 가능).
- 저장소는 Upstash 대신 `DATA_DIR`(/data 볼륨)의 JSON 파일을 씁니다.
- 기본은 서브도메인(예: finance.hosu.me) 서비스이고, 필요하면 `BASE_PATH=/finance` 로 하위 경로에서도 돌릴 수 있습니다.
- **토스증권 보유 종목 동기화** (`lib/toss.js`, `api/toss.js`): `TOSS_CLIENT_ID`/`TOSS_CLIENT_SECRET` 이 있으면 켜집니다.
  토스는 허용 IP 에서만 응답하므로 IP 가 고정된 곳(집 NAS)에서만 동작합니다. 조회 API 만 쓰고 주문 API 는 부르지 않습니다.
- 설정 예시: `.env.example`, 구성: `Dockerfile`, `docker-compose.yml`

## 로컬에서 실행

```
powershell -ExecutionPolicy Bypass -File dev-server.ps1
```
브라우저에서 http://localhost:8787 을 엽니다. (로컬에서는 서버 저장·알림 없이 브라우저 저장으로 동작)

## 배포

이 폴더는 `https://github.com/GimHosu/stock-signal-desk` 에 연결되어 있고, `main` 에 올리면 Vercel이 자동으로 다시 배포합니다.

## 알아둘 점

- 알림을 설정하면 종목 목록이 서버에 저장되어 모든 기기에서 같은 목록이 보입니다. 설정 전에는 브라우저에만 저장됩니다.
- 장중에는 1분마다, 그 외에는 30분마다 다시 분석합니다. 장중 신호는 잠정이며 장 마감까지 바뀔 수 있습니다.
- Yahoo Finance 비공식 API를 사용하므로 예고 없이 막히거나 바뀔 수 있습니다.
- 이 앱의 신호는 기계적 규칙의 결과일 뿐 투자 권유가 아닙니다.
